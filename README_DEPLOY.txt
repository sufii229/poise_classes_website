RUN LOCALLY:
1. Install Node.js 18+.
2. Open terminal in this folder.
3. Run: npm start
4. Open http://localhost:3000
5. Admin: http://localhost:3000/admin.html

DEFAULT ADMIN (CHANGE BEFORE PUBLICATION):
Username: admin
Password: POISE@2026
For a real deployment set ADMIN_USER and ADMIN_PASS environment variables.

LIVE DEPLOYMENT:
Use a Node.js-capable hosting service with persistent storage. Point your domain to the host, enable HTTPS/SSL, set ADMIN_USER and ADMIN_PASS, then start the app with npm start. Keep the data/ folder persistent so registrations are not lost on restart/redeploy.

GOOGLE:
After the site is live at its final domain, add the domain to Google Search Console, verify ownership, submit /sitemap.xml, and use URL Inspection -> Request indexing for the homepage. Google controls when a page is crawled/indexed; submitting does not guarantee immediate inclusion.

NOTIFICATION NOTE:
The included dashboard gives live browser notifications while it is open. For WhatsApp/SMS/email alerts even when the dashboard is closed, an external notification provider and credentials are required; no such secret credentials are included in this package.

PAYMENT NOTE:
This version uses manual UPI/QR payment verification. It does not automatically verify bank/UPI payments. A payment gateway can be integrated later.

SECURITY:
